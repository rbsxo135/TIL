# Webserver

## Apache
- Process/Thread based
- Less powerful than Nginx in the environment that many users access to the server at the same time
- Possess high memory
- Dynamic Contant

## Nginx
- Event based asynchronized architecture
- Powerful in the environment that many users access to the server at the same time
- Possess less memory
- Static content, **Reverse Proxy**

## Virtual Host
- Allow a single server to run multiple
