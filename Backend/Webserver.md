# Webserver  

## Apache
- Process/Thread based
- Less powerful than Nginx in the environment that many users access to the server at the same time
- Possess high memory
- Dynamic Contant

## Nginx
- Event based asynchronized architecture
- Powerful in the environment that many users access to the server at the same time
- Possess less memory
- Static content, **Reverse Proxy**

## Nodejs
- Event-driven, Non-blocking I/O model
- Powerful in the environment that handles many concurrent connections with lightweight tasks (e.g., Real-time chat, API server)
- Single-threaded event loop architecture
- JavaScript on the server-side

## Express
- Minimal and flexible **web framework for Node.js**
- Middleware-based architecture
- Routing and REST API development
- Static file serving

## Virtual Host
- Allow a single server to run multiple
